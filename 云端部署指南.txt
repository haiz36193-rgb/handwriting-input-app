============================================
免费云服务器部署指南 - 小范围测试
============================================

一、推荐免费云平台
============================================

方案1：Railway（最推荐）
- 免费额度：$5/月
- 支持：MySQL、Redis、Docker
- 自动HTTPS
- 自动域名：*.railway.app
- 优点：配置简单，一键部署
- 缺点：免费额度有限，适合小范围测试

方案2：Render
- 免费套餐：512MB内存
- 支持：Docker容器
- 自动HTTPS
- 需要外部数据库（如PlanetScale免费版）
- 优点：稳定性好
- 缺点：需要额外配置数据库

方案3：Fly.io
- 免费额度：160小时/月
- 全球边缘部署
- 支持Docker
- 自动HTTPS
- 优点：性能好，全球加速
- 缺点：配置相对复杂

方案4：Oracle Cloud Always Free
- 永久免费2台VM（1 OCPU, 1GB RAM）
- 需要信用卡验证
- 优点：完全免费，永久使用
- 缺点：配置复杂，需要运维能力

============================================
推荐使用 Railway 部署步骤
============================================

二、Railway 部署步骤
============================================

1. 注册账号
   访问：https://railway.app/
   使用GitHub账号登录

2. 创建新项目
   - 点击 "New Project"
   - 选择 "Deploy from GitHub repo"
   - 授权访问您的GitHub仓库

3. 准备代码仓库
   将项目推送到GitHub：
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/yourusername/handwriting-input-app.git
   git push -u origin main

4. 在Railway配置服务

   步骤1：添加MySQL数据库
   - 点击 "New Service"
   - 选择 "Database"
   - 选择 "MySQL"
   - Railway会自动创建MySQL实例

   步骤2：添加Redis缓存
   - 点击 "New Service"
   - 选择 "Database"
   - 选择 "Redis"
   - Railway会自动创建Redis实例

   步骤3：添加后端服务
   - 点击 "New Service"
   - 选择 "Deploy from GitHub repo"
   - 选择您的项目仓库
   - 选择 "backend" 目录

5. 配置环境变量

   在后端服务中添加以下环境变量：

   SPRING_DATASOURCE_URL=jdbc:mysql://mysql:3306/handwriting_input_app?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true

   SPRING_DATASOURCE_USERNAME=${{MYSQL.USERNAME}}
   SPRING_DATASOURCE_PASSWORD=${{MYSQL.PASSWORD}}
   SPRING_REDIS_HOST=${{REDIS.PUBLIC_URL}}
   SPRING_REDIS_PORT=6379
   JWT_SECRET=your-strong-secret-key-here-change-in-production
   TZ=Asia/Shanghai

6. 修改应用配置

   需要修改的文件：
   - backend/src/main/resources/application-prod.yml
   - backend/Dockerfile

   主要修改：
   - 移除硬编码的localhost地址
   - 使用环境变量配置
   - 添加健康检查端点

7. 初始化数据库

   方式1：通过Railway的控制台执行SQL
   方式2：在应用启动时自动执行

8. 部署

   - 点击 "Deploy"
   - 等待构建完成
   - Railway会自动分配域名：*.railway.app

9. 测试

   - 访问分配的域名测试API
   - 测试注册/登录功能
   - 验证数据库连接

============================================
三、前端APP配置更新
============================================

需要修改前端配置文件，使其连接到云端服务器：

文件：frontend/lib/utils/app_config.dart

修改前：
static const String baseUrl = 'http://192.168.1.10:8080/api/v1';

修改后：
static const String baseUrl = 'https://your-app.railway.app/api/v1';

重新编译APK：
cd frontend
flutter build apk --release

新的APK文件位置：
frontend/build/app/outputs/flutter-apk/app-release.apk

============================================
四、域名绑定（可选）
============================================

如果您有自己的域名：

1. 在域名服务商处添加CNAME记录：
   主机记录：api
   记录类型：CNAME
   记录值：your-app.railway.app

2. 在Railway中配置域名：
   - 进入项目设置
   - 选择 "Domains"
   - 添加自定义域名
   - Railway会自动配置HTTPS

七、注意事项
============================================

1. 安全建议：
   - 修改JWT密钥为强密钥
   - 启用HTTPS（Railway自动配置）
   - 定期更新依赖包

3. 数据保护：
   - 定期备份数据库

   - 使用环境变量管理密钥

4. 用户体验：
   - 优化APK大小
   - 添加启动动画
   - 完善错误提示
