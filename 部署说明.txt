===========================================
个性化手写输入法APP - 部署说明
===========================================

一、环境要求
===========================================
1. JDK 11 或更高版本
2. Maven 3.6+
3. MySQL 8.0+
4. Redis 6.0+
5. 操作系统：Windows/Linux/macOS

二、部署步骤
===========================================

1. 数据库初始化
   cd scripts
   init-db.bat

2. 配置文件修改
   编辑 backend/src/main/resources/application.yml
   - 修改数据库连接信息
   - 修改Redis连接信息
   - 修改JWT密钥

3. 启动后端服务
   cd backend
   mvn clean package
   java -jar target/handwriting-input-app-1.0.0.jar

4. 启动前端应用
   cd frontend
   flutter pub get
   flutter run

三、服务地址
===========================================
后端API: http://localhost:8080/api/v1
前端应用: 根据Flutter启动输出

四、默认账号
===========================================
测试用户: 18612345678 / test123456

五、注意事项
===========================================
1. 所有数据存储在本地MySQL数据库
2. CORS仅允许本地访问
3. 深度学习模型为占位符，需替换为真实模型
4. 文件上传使用本地存储路径

六、生产环境部署
===========================================
使用 application-prod.yml 配置文件
启动命令: java -jar target/handwriting-input-app-1.0.0.jar --spring.profiles.active=prod
