# 启动说明

## 快速启动

**双击运行**：`启动.bat`

## 使用步骤

### 第一步：安装工具（如果还没安装）

1. 双击 `启动.bat`
2. 选择 `2` - 安装开发工具
3. 按照提示下载并安装：
   - MySQL 8.0
   - Maven 3.6+
   - Flutter 3.x

### 第二步：检查环境

1. 双击 `启动.bat`
2. 选择 `1` - 检查环境配置
3. 确认所有工具都已安装

### 第三步：初始化数据库

1. 双击 `启动.bat`
2. 选择 `4` - 初始化数据库
3. 输入MySQL root密码
4. 等待完成

### 第四步：启动项目

1. 双击 `启动.bat`
2. 选择 `6` - 启动项目（前后端）
3. 等待服务启动

## 菜单选项说明

| 选项 | 功能 |
|------|------|
| 1 | 检查环境配置 |
| 2 | 安装开发工具 |
| 3 | 安装Redis（可选） |
| 4 | 初始化数据库 |
| 5 | 配置阿里云OSS（可选） |
| 6 | 启动项目（前后端） |
| 7 | 只启动后端 |
| 8 | 只启动前端 |
| 0 | 退出 |

## 常见问题

### Q: 启动脚本打不开？

A: 右键点击 `启动.bat`，选择"以管理员身份运行"

### Q: 提示找不到命令？

A: 确保已经安装了MySQL、Maven、Flutter，并添加到系统PATH

### Q: 数据库连接失败？

A: 检查MySQL服务是否启动，root密码是否正确

### Q: Maven下载依赖慢？

A: 配置国内镜像源，编辑 `~/.m2/settings.xml`
