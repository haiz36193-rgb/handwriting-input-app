============================================
方式2：手动部署
-----------------------------------

如果自动脚本失败，可以手动执行以下命令：

# 1. 更新系统
sudo apt-get update

# 2. 安装Docker
sudo apt-get install -y docker.io
sudo systemctl start docker
sudo systemctl enable docker

# 3. 安装Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 4. 安装Git和Maven
sudo apt-get install -y git maven

# 5. 克隆项目
git clone https://github.com/haiz36193-rgb/handwriting-input-app.git
cd handwriting-input-app

# 6. 配置环境变量
cp .env.example .env
nano .env
# 修改密码后保存

# 7. 构建后端
cd backend
mvn clean package -DskipTests
cd ..

# 8. 启动服务
docker-compose -f docker-compose.aliyun.yml up -d

# 9. 查看日志
docker-compose -f docker-compose.aliyun.yml logs -f

============================================
常见问题
============================================

问题1：SSH连接失败
-----------------------------------
- 检查服务器是否运行
- 检查安全组是否开放22端口
- 确认密码正确

问题2：Docker安装失败
-----------------------------------
# 手动安装Docker
sudo apt-get install -y docker.io
sudo systemctl start docker

问题3：构建失败
-----------------------------------
# 检查内存
free -h

# 如果内存不足，增加swap
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

问题4：服务启动失败
-----------------------------------
# 查看日志
docker-compose -f docker-compose.aliyun.yml logs backend

# 重启服务
docker-compose -f docker-compose.aliyun.yml restart
