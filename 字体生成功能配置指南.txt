===========================================
字体生成功能配置指南
===========================================

一、字体生成概述
===========================================
功能说明：基于用户手写笔迹生成个性化字体文件
输出格式：TTF (TrueType Font) 或 OTF (OpenType Font)
字号范围：12-72号
美化模式：自然还原、清晰优化、艺术加工

二、字体生成流程
===========================================
1. 用户上传手写笔迹
2. 系统提取笔迹特征
3. 基于特征生成字体轮廓
4. 应用美化模式
5. 导出为TTF/OTF文件
6. 用户下载使用

三、字体渲染引擎安装
===========================================

1. 安装FontForge
   Windows：
   下载：https://fontforge.org/downloads/
   安装：运行安装程序，按提示完成
   
   或使用Python版本：
   pip install fontforge

2. 安装Python字体库
   pip install fonttools
   pip install bezier
   pip install fontforge

3. 验证安装
   python -c "import fontforge; print('OK')"

四、字体生成实现
===========================================

1. 字体轮廓生成
   - 将笔画转换为贝塞尔曲线
   - 计算控制点坐标
   - 优化曲线平滑度

2. 字符间距调整
   - 根据用户书写习惯调整
   - 保持字符间一致性

3. 字体元数据
   - 字体名称
   - 字体版本
   - 版权信息
   - 字符编码

五、美化模式说明
===========================================

1. 自然还原模式（mode=1）
   - 最大程度保留原始书写风格
   - 轻微优化笔画连接
   - 适合个性化要求高的场景

2. 清晰优化模式（mode=2）
   - 平滑笔画边缘
   - 统一笔画粗细
   - 提高可读性
   - 适合正式文档使用

3. 艺术加工模式（mode=3）
   - 增强艺术效果
   - 添加装饰元素
   - 适合创意设计使用

六、字体生成API
===========================================

1. 生成字体
   POST /api/v1/font/generate
   参数：
   - fontName: 字体名称
   - handwritingIds: 笔迹ID列表
   - beautifyMode: 美化模式（1/2/3）
   
   返回：
   - fontId: 字体ID
   - generateStatus: 生成状态

2. 查询状态
   GET /api/v1/font/status/{fontId}
   
   返回：
   - status: 0=生成中，1=已完成，2=失败
   - fontUrl: 字体下载地址（完成后）

3. 下载字体
   GET /api/v1/font/download/{fontId}
   
   返回：
   - TTF/OTF文件

七、字体使用
===========================================

1. 安装字体
   Windows：
   - 右键TTF文件 -> 安装
   - 或复制到 C:\Windows\Fonts
   
   Mac：
   - 双击TTF文件 -> 安装字体
   
   Linux：
   - 复制到 ~/.fonts/
   - 运行 fc-cache -fv

2. 在应用中使用
   - 设置为系统默认字体
   - 在文档中选择该字体
   - 在网页中使用（@font-face）

八、注意事项
===========================================
1. 字体生成需要一定的计算时间，请耐心等待
2. 生成的字体文件可能较大（几MB）
3. 不同字符数量会影响生成时间
4. 建议先生成常用字符集（3000+字符）
5. 字体文件仅供个人使用，请勿商用
