============================================
快速部署到Railway - 5分钟完成
============================================

一、准备阶段（本地）
============================================

1. 运行部署脚本
   双击：deploy-to-railway.bat

2. 等待编译完成
   - 脚本会自动编译项目
   - 更新Git仓库
   - 准备配置文件

============================================
二、部署阶段（Railway网站）
============================================

1. 访问Railway
   https://railway.app/
   使用GitHub账号登录

2. 创建新项目
   点击 "New Project" → "Deploy from GitHub repo"

3. 选择仓库
   选择您的handwriting-input-app仓库
   点击 "Deploy Now"

4. 添加数据库服务
   点击 "New Service" → "Database" → "MySQL"
   等待创建完成

5. 添加Redis服务
   点击 "New Service" → "Database" → "Redis"
   等待创建完成

6. 配置后端服务
   点击后端服务 → "Variables"
   添加以下环境变量：

   DATABASE_URL=jdbc:mysql://<mysql-host>:3306/handwriting_input_app?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true

   DATABASE_USERNAME=<从MySQL服务获取>
   DATABASE_PASSWORD=<从MySQL服务获取>

   REDIS_HOST=<从Redis服务获取>
   REDIS_PORT=6379

   JWT_SECRET=生成一个强密钥（建议64位随机字符串）

7. 重启服务
   点击 "Redeploy" 使配置生效

============================================
三、获取信息
============================================

1. 查看MySQL连接信息
   - 点击MySQL服务
   - 在"Variables"标签页查看：
     * MYSQLDATABASE=handwriting_input_app
     * MYSQLHOST=mysql.railway.app
     * MYSQLUSERNAME=your-username
     * MYSQLPASSWORD=your-password
     * MYSQLPORT=3306

2. 查看Redis连接信息
   - 点击Redis服务
   - 在"Variables"标签页查看：
     * REDISHOST=redis.railway.app
     * REDISPORT=6379

3. 查看后端服务地址
   - 点击后端服务
   - 在"Domains"标签页查看分配的域名
   - 格式：https://your-app.railway.app

============================================
六、更新前端APP
============================================

1. 修改配置文件
   文件：frontend\lib\utils\app_config.dart
   修改前：static const String baseUrl = 'http://192.168.1.10:8080/api/v1';
   修改后：static const String baseUrl = 'https://your-app.railway.app/api/v1';

2. 重新编译APK
   cd frontend
   flutter build apk --release

3. 获取APK文件
   位置：frontend\build\app\outputs\flutter-apk\app-release.apk

4. 分发APK
   - 上传到文件分享平台
   - 通过微信/QQ发送
   - 上传到应用商店

============================================
八、常见问题
============================================

Q1: 部署后无法访问？
A: 检查防火墙设置，确保8080端口开放

Q2: 数据库连接失败？
A: 检查环境变量配置是否正确

Q3: Redis连接失败？
A: 确认Redis服务已启动，检查连接信息

Q4: APP无法连接服务器？
A: 确认baseUrl配置正确，使用HTTPS协议

Q5: 免费额度不够用？
A: 监控使用情况，优化性能，或升级付费套餐
