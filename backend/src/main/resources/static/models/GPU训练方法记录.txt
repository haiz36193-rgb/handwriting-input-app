## 3.1 训练参数配置
```python
# 基础配置
BASE_DIR = r"C:\Users\Administrator\handwriting-input-app\backend\src\main\resources\static\models"
MODEL_DIR = os.path.join(BASE_DIR, "models_output")
RESUME_CHECKPOINT = os.path.join(MODEL_DIR, "optimized_checkpoint_stepXXXX.pth")

# 训练参数
BATCH_SIZE = 16
GRADIENT_ACCUMULATION = 2
CLEAN_INTERVAL = 20
SAVE_INTERVAL = 1000          # 每1000步保存一次checkpoint
NUM_EPOCHS = 20
LEARNING_RATE = 0.0005
WEIGHT_DECAY = 0.0001
IMG_SIZE = 128

# 设备配置
DEVICE = torch.device("cuda" if torch.cuda.is_available() else "cpu")
```

## 3.2 数据增强配置
```python
TRAIN_TRANSFORMS = transforms.Compose([
    transforms.Grayscale(),
    transforms.Resize((IMG_SIZE, IMG_SIZE)),
    transforms.RandomRotation(10),           # 随机旋转10度
    transforms.RandomAffine(degrees=0, translate=(0.1, 0.1)),  # 随机平移
    transforms.ToTensor(),
    transforms.Normalize([0.5], [0.5])
])
```

## 3.3 Checkpoint自动清理策略
```python
# 每次保存新checkpoint后，自动删除旧checkpoint（只保留最新的3个）
all_checkpoints = [f for f in os.listdir(MODEL_DIR) if f.startswith("optimized_checkpoint_step") and f.endswith(".pth")]
all_checkpoints.sort()
if len(all_checkpoints) > 3:
    for old_checkpoint in all_checkpoints[:-3]:
        old_path = os.path.join(MODEL_DIR, old_checkpoint)
        os.remove(old_path)
```

8. 常见问题处理
===================================

## 8.1 模型架构不匹配
错误: RuntimeError: Error(s) in loading state_dict
解决: 确保训练脚本中的模型架构与checkpoint中的架构完全匹配

## 8.2 磁盘写入失败
错误: RuntimeError: PytorchStreamWriter failed writing file
解决:
1. 检查磁盘空间是否充足
2. 增加checkpoint保存间隔（从50步改为1000步）
3. 自动清理旧checkpoint文件

## 8.3 Conda TOS错误
错误: CondaToSNonInteractiveError: Terms of Service have not been accepted
解决: 运行conda tos accept命令接受服务条款

## 8.4 CUDA不可用
错误: CUDA可用: False
解决:
1. 确认GPU驱动已正确安装
2. 确认CUDA版本与PyTorch版本匹配
3. 使用conda安装PyTorch GPU版本

10. 注意事项
===================================

1. **磁盘空间**: 训练过程中会产生大量checkpoint文件，必须配置自动清理
2. **模型架构**: 确保训练脚本中的模型架构与要恢复的checkpoint完全匹配
3. **GPU内存**: 监控GPU内存使用，避免OOM错误
4. **训练中断**: 训练可以随时中断，下次会从最新checkpoint继续
5. **数据增强**: 保持数据增强配置一致，确保训练稳定性
6. **学习率调度**: 使用ReduceLROnPlateau调度器自动调整学习率
7. **内存清理**: 定期清理GPU和系统内存，避免内存泄漏
