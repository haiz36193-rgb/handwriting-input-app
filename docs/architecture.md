# 技术架构设计文档

## 1. 系统架构概述

### 1.1 架构风格
采用微服务架构，前后端分离设计，支持高并发、高可用、可扩展。

### 1.2 技术栈选型

#### 后端技术栈
- **框架**: Spring Boot 2.7.x
- **语言**: Java 11
- **数据库**: MySQL 8.0（主从架构）
- **缓存**: Redis 6.0
- **对象存储**: 阿里云OSS
- **API文档**: Swagger 3.0
- **构建工具**: Maven 3.8.x
- **容器化**: Docker + Docker Compose

#### 前端技术栈
- **框架**: Flutter 3.0+
- **语言**: Dart 2.17+
- **状态管理**: Provider
- **网络请求**: Dio
- **本地存储**: SharedPreferences + Hive
- **UI组件**: Material Design 3

## 3. 微服务模块设计

### 3.1 用户服务 (User Service)
**职责**: 用户注册、登录、认证、个人信息管理

**核心功能**:
- 用户注册（手机号/微信）
- 用户登录（JWT Token认证）
- 个人信息管理
- 笔迹数据管理
- 字体管理

**技术要点**:
- Spring Security + JWT
- BCrypt密码加密
- Redis缓存Session

### 3.2 笔迹采集服务 (Handwriting Collection Service)
**职责**: 接收用户手写笔迹数据

**核心功能**:
- 直接手写数据采集
- 扫描文档笔迹提取
- 笔迹数据预处理
- 笔迹质量检测

**技术要点**:
- 文件上传（支持多种格式）
- 图像预处理（去噪、矫正、分割）
- 数据验证与清洗

### 3.3 特征识别服务 (Feature Recognition Service)
**职责**: 提取手写笔迹特征

**核心功能**:
- 笔画顺序识别
- 起笔收笔力度识别
- 连笔弧度识别
- 字间距识别
- 书写节奏识别

**技术要点**:
- CNN+RNN深度学习模型
- 特征提取算法
- 模型推理服务

### 3.4 字体生成服务 (Font Generation Service)
**职责**: 根据笔迹特征生成专属字体

**核心功能**:
- 特征映射与字体渲染
- 多字号适配（12-72号）
- 字体美化优化
- 字体格式转换（TTF/OTF）

**技术要点**:
- 字体渲染引擎
- 贝塞尔曲线优化
- 字体压缩与优化

### 3.5 云存储服务 (Cloud Storage Service)
**职责**: 管理笔迹数据和字体文件的存储

**核心功能**:
- 笔迹原始数据存储
- 字体文件存储
- 数据备份与恢复
- 跨设备同步

**技术要点**:
- 阿里云OSS集成
- 数据加密存储
- CDN加速

## 4. 数据流设计

### 4.1 用户注册流程
```
用户 → 输入注册信息 → 前端验证 → 用户服务 → MySQL → Redis缓存 → 返回Token
```

### 4.2 笔迹采集流程
```
用户 → 手写/上传文档 → 笔迹采集服务 → 数据预处理 → 云存储服务 → 特征识别服务
```

### 4.3 字体生成流程
```
笔迹特征 → 字体生成服务 → 特征映射 → 字体渲染 → 字体优化 → 云存储服务
```

### 4.4 登录后输入流程
```
用户输入 → 输入法框架 → 获取用户字体 → 调用字体渲染 → 输出手写笔迹
```
