下一步操作（在Railway网站完成）
============================================

步骤1：访问Railway
-----------------------------------
浏览器打开：https://railway.app/
使用GitHub账号登录

步骤2：创建新项目
-----------------------------------
1. 点击 "New Project" 按钮
2. 选择 "Deploy from GitHub repo"
3. 授权访问GitHub仓库

步骤3：创建GitHub仓库
-----------------------------------
如果还没有GitHub仓库，需要先创建：

方式A：通过Railway创建
1. 在Railway中选择 "New Project"
2. 选择 "Deploy from GitHub repo"
3. 点击链接创建新仓库

方式B：手动创建
1. 访问 https://github.com/new
2. 创建新仓库：handwriting-input-app
3. 复制仓库URL
4. 在本地执行：
   git remote add origin https://github.com/你的用户名/handwriting-input-app.git
   git push -u origin master

步骤4：添加MySQL数据库
-----------------------------------
1. 在Railway项目页面点击 "New Service"
2. 选择 "Database"
3. 选择 "MySQL"
4. 等待创建完成
5. 记录数据库连接信息（在Variables标签）

步骤5：添加Redis缓存
-----------------------------------
1. 点击 "New Service"
2. 选择 "Database"
3. 选择 "Redis"
4. 等待创建完成
5. 记录Redis连接信息（在Variables标签）

步骤6：添加后端服务
-----------------------------------
1. 点击 "New Service"
2. 选择 "Deploy from GitHub repo"
3. 选择您的handwriting-input-app仓库
4. 选择 "backend" 目录
5. 点击 "Deploy Now"

步骤7：配置环境变量
-----------------------------------
点击后端服务 → "Variables" → "New Variable"

添加以下环境变量：

DATABASE_URL=
jdbc:mysql://<mysql-host>:3306/handwriting_input_app?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true

DATABASE_USERNAME=<从MySQL服务的Variables获取>
DATABASE_PASSWORD=<从MySQL服务的Variables获取>

REDIS_HOST=<从Redis服务的Variables获取>
REDIS_PORT=6379

JWT_SECRET=
生成一个强密钥（建议64位随机字符串）
可以使用在线工具生成：https://randomkeygen.com/

PORT=8080

步骤8：重启服务
-----------------------------------
1. 点击 "Redeploy" 按钮
2. 等待重新部署完成
3. 查看日志确认启动成功

步骤9：初始化数据库
-----------------------------------
方式1：使用Railway控制台
1. 点击MySQL服务
2. 点击 "Console" 标签
3. 执行SQL脚本（参考scripts/init.sql）

方式2：使用数据库工具
1. 使用MySQL Workbench或DBeaver
2. 使用Railway提供的连接信息连接
3. 执行初始化SQL脚本

步骤10：测试部署
-----------------------------------
1. 查看后端服务分配的域名
   - 点击后端服务
   - 在"Domains"标签查看
   - 格式：https://your-app.railway.app

2. 测试健康检查
   访问：https://your-app.railway.app/api/v1/health
   应该返回：
   {"status":"UP","timestamp":"...","service":"handwriting-input-app","version":"1.0.0"}

3. 测试用户注册
   POST https://your-app.railway.app/api/v1/user/register
   Body: {"username":"test","email":"test@example.com","password":"123456"}

4. 测试用户登录
   POST https://your-app.railway.app/api/v1/user/login
   Body: {"username":"test","password":"123456"}

============================================
部署完成后的操作
============================================

更新前端APP配置
-----------------------------------
1. 修改文件：frontend/lib/utils/app_config.dart

   修改前：
   static const String baseUrl = 'http://192.168.1.10:8080/api/v1';

   修改后：
   static const String baseUrl = 'https://your-app.railway.app/api/v1';

   注意：将your-app.railway.app替换为实际分配的域名

2. 重新编译APK
   cd frontend
   flutter build apk --release

3. 获取新的APK文件
   位置：frontend/build/app/outputs/flutter-apk/app-release.apk

4. 分发给测试用户
   - 上传到文件分享平台
   - 通过微信/QQ发送
   - 上传到应用商店

故障排除
